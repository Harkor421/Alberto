## 📖 Sobre el proyecto

Bot de Discord con música desde YouTube, paginación de embeds, colectores de reacciones y persistencia en MySQL.

## ✨ Qué hace

- Música desde YouTube con ytdl-core
- Paginación de embeds y colectores de reacciones
- Persistencia en MySQL
- Discord.js · Procfile listo para desplegar
